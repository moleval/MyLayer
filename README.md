# MyLayer — модули слоёв AutoCAD

Набор LISP-модулей для переноса слоёв, фильтров и переменных слоёв между DWG-чертежами через Excel-XML (формат 2003). Разработано под AutoCAD 2013/LT 2013, работает и в более новых версиях (2018, 2023 и т. д.).

---

## Состав

| Файл | Назначение |
|---|---|
| `00_LoaderChecker.lsp` | Загрузчик и проверка синтаксиса LISP-файлов |
| `01_Variables.lsp` | Создание слоёв шаблона + установка переменных слоёв |
| `02_LayerExport.lsp` | Выгрузка слоёв и фильтров в XML |
| `03_LayerImport.lsp` | Загрузка слоёв и фильтров из XML |

Порядок загрузки строго фиксирован: **00 → 01 → 02 → 03**.

---

## Быстрый старт

### Первая установка

```
(load "D:/MyLayer/00_LoaderChecker.lsp")
МОИСЛОИЗАГРУЗЧИК
```

### Чертёж-источник (откуда переносим слои)

```
МОИСЛОИВЫГРУЗКА
```

Создаётся файл `<ИмяЧертежа> Слои.xml` в папке чертежа.

### Чертёж-приёмник (куда переносим)

```
МОИСЛОИЗАГРУЗИТЬ
```

Слои и фильтры переносятся, переменные применяются автоматически.

## Функционал

### `00_LoaderChecker.lsp` — загрузчик

- Проверяет синтаксис LISP-файлов: баланс скобок, незакрытые строки (с поддержкой многострочных), экранирование.
- Загружает модули только после успешной проверки.
- Показывает количество строк в каждом файле.

### `01_Variables.lsp` — переменные слоёв

- Хранит реестр **8 слоёв** шаблона с полными параметрами (ACI, тип линии, вес, описание).
- Создаёт их в чертеже, автоматически подгружая недостающие типы линий из `acad.lin`/`acadiso.lin`.
- Устанавливает **9 переменных** слоёв: `TEXTLAYER`, `DIMLAYER`, `HPLAYER`, `MLEADERLAYER`, `CENTERLAYER`, `TABLELAYER`, `REVCLOUDLAYER`, `VIEWPORTLAYER`, `XREFLAYER`.
- Пропускает неподдерживаемые версией AutoCAD переменные с пометкой `Не в этой версии`.
- Показывает текущие значения всех переменных.

### `02_LayerExport.lsp` — выгрузка

- Экспортирует **все слои** чертежа в Excel-XML 2003 (кодировка Windows-1251): имя, описание, ACI, TrueColor, тип линии, вес, прозрачность, стиль печати, состояние (видимость/заморозка/блокировка), флаги 70.
- Экспортирует **имена фильтров слоёв** (состав фильтров через LISP в AutoCAD 2013 недоступен — заполняется в Excel вручную).
- Показывает таблицу выгрузки в командной строке.

### `03_LayerImport.lsp` — загрузка

- **Читает XML** в кодировке из пролога (`encoding=`) или перебором: `utf-8` → `windows-1251` → `unicode`.
- **Создаёт/обновляет слои** из листа «Слои».
- **Сохраняет для существующих слоёв** видимость, заморозку, «заморожен в новых ВЭ» и блокировку — они не перезаписываются из XML.
- **Пересоздаёт фильтры** слоёв: существующие с теми же именами молча удаляются (2 прохода — от листьев к корням), затем создаются заново.
- Поддерживает **вложенные фильтры** через `>>Имя` (`A >>B` = «B вложен в A»).
- Автоматически поднимает слои потомков в родителя (обход ограничения AutoCAD 2013).
- В конце вызывает `МОИСЛОИПОУМОЛЧАНИЮ` (если модуль 01 загружен).
- Показывает предупреждения отдельной таблицей (не разрывая список слоёв).

## Команды

### Загрузчик (модуль 00)

| Команда | Действие |
|---|---|
| `МОИСЛОИЗАГРУЗЧИК` | Проверить синтаксис и загрузить модули 01–03 |
| `МОИСЛОИПРОВЕРКАМОДУЛЕЙ` | Только проверить модули (без загрузки) |
| `МОИСЛОИПРОВЕРКАФАЙЛА` | Проверить один LSP-файл, выбранный вручную |

### Переменные слоёв (модуль 01)

| Команда | Действие |
|---|---|
| `МОИСЛОИСОЗДАТЬ` | Создать 8 слоёв шаблона с полными свойствами + установить переменные |
| `МОИСЛОИПОУМОЛЧАНИЮ` | Только установить переменные (слои уже должны быть в чертеже) |
| `МОИСЛОИТЕКУЩИЕ` | Показать текущие значения переменных слоёв |

### Выгрузка (модуль 02)

| Команда | Действие |
|---|---|
| `МОИСЛОИВЫГРУЗКА` | Выгрузить слои и фильтры в `<ИмяЧертежа> Слои.xml` |

### Загрузка (модуль 03)

| Команда | Действие |
|---|---|
| `МОИСЛОИЗАГРУЗИТЬ` | Загрузить слои и фильтры из XML; в конце применить переменные |
| `МОИСЛОИПРОВЕРИТЬXML` | Диагностика XML: кодировка, наличие листов, структура |
| `МОИСЛОИФИЛЬТРЫОЧИСТИТЬ` | Удалить фильтры слоёв, перечисленные в XML-шаблоне |

## Что получается в результате

### Файл `<ИмяЧертежа> Слои.xml`

Excel-совместимый XML с двумя листами.

**Лист «Слои»** — 20 колонок:

| Имя слоя | Описание | Цвет ACI | Цвет имя | Цвет метод | R | G | B | Тип линии | Вес линии код | Вес линии текст | Прозрачность | Стиль печати | Включен | Заморожен | Заморожен в новых ВЭ | Заблокирован | Печатается | Зависит от XREF | Флаги 70 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

**Лист «Фильтры»** — 2 колонки:

| Имя фильтра | Список слоев |
|---|---|

Столбец «Список слоев» заполняется вручную в Excel:

- обычные слои через запятую: `Витражи,Адаптер алюминиевый,Адаптер ПВХ`;
- вложенные фильтры через `>>`: `>>Подсистема` (означает «Подсистема вложена внутрь этого фильтра»).

### 8 слоёв шаблона (модуль 01)

| Слой | ACI | Тип линии | Вес | Назначение |
|---|---|---|---|---|
| `0` | 7 | Continuous | По умолчанию | Системный, для XREFLAYER |
| `Текст` | 2 | Continuous | 0.15 мм | TEXTLAYER |
| `Размеры` | 14 | Continuous | 0.13 мм | DIMLAYER, TABLELAYER |
| `Штриховка` | 44 | Continuous | 0.09 мм | HPLAYER |
| `Обозначения` | 14 | Continuous | 0.09 мм | MLEADERLAYER |
| `Штрихпунктирные и осевые` | 14 | GOST2.303 6 | 0.00 мм | CENTERLAYER |
| `Тонкая` | 110 | Continuous | 0.13 мм | REVCLOUDLAYER |
| `Невидимые` | 250 | Continuous | 0.13 мм | VIEWPORTLAYER |

### Поведение существующих слоёв

При импорте XML **в существующие слои**:

| Параметр | Что происходит |
|---|---|
| Цвет ACI | Значение из XML, знак — от текущего (видимость сохраняется) |
| Тип линии | Из XML |
| Вес линии | Из XML |
| Описание | Из XML |
| Прозрачность / стиль печати | Из XML |
| **Видимость (вкл/выкл)** | **НЕ ТРОГАЕТСЯ** |
| **Заморожен** | **НЕ ТРОГАЕТСЯ** |
| **Заморожен в новых ВЭ** | **НЕ ТРОГАЕТСЯ** |
| **Заблокирован** | **НЕ ТРОГАЕТСЯ** |

Для **новых** слоёв применяются все параметры из XML без ограничений.

## Ограничения

- Переносятся только слои и фильтры. Объекты чертежа, блоки, текстовые стили, размерные стили, типы линий **не экспортируются**.
- В XML не выгружается состав фильтров — заполняется вручную в Excel.
- Переменные слоёв (модуль 01) не переносятся через XML — применяются отдельной командой после импорта (или автоматически, если модуль 01 загружен).
- Если шаблон XML содержит опечатку в имени слоя (например, `Штрихпунктрирные` вместо `Штрихпунктирные`) — переменная `CENTERLAYER` не свяжется с этим слоем. Следите за согласованностью имён между XML и `*LV:LAYERS*` / `*LV:VARS*`.

---

## Требования

- AutoCAD 2013 / LT 2013 или новее (проверено на 2018, 2023).
- Поддержка ActiveX (`vl-load-com`).
- ADODB.Stream (Windows) для чтения UTF-8/1251 XML.
