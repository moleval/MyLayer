# MyLayer — слои, фильтры и переменные слоёв AutoCAD

Монолитный LISP-модуль для переноса слоёв, фильтров и переменных слоёв между
DWG-чертежами через Excel-XML (формат 2003). Разработан под AutoCAD 2013 / LT 2013,
работает в 2018, 2023 и новее.

---

## Состав

| Файл | Назначение |

| `MyLayer.lsp` | Монолит: слои шаблона, переменные, экспорт/импорт, фильтры, `АР`, `Нераспределённые`, проверка файла |

## Быстрый старт

```lisp
(load "D:/MyLayer/MyLayer.lsp")
```

После загрузки печатается баннер с 13 командами.

### Чертёж-источник

```text
МОИСЛОИВЫГРУЗКА
```

Создаётся `Слои и фильтры.xml` в папке чертежа. Выгружаются только слои
фильтра-корня `Стройплэкс` (настройка `*LX:ROOT-FILTER*`), а не все слои чертежа.

### Чертёж-приёмник

```text
МОИСЛОИЗАГРУЗИТЬ
```

Слои создаются/обновляются, фильтры пересоздаются, в конце создаются `АР` и
`Нераспределённые`, применяются переменные слоёв.

## Экспорт

- Excel-XML 2003, Windows-1251, два листа: «Слои» и «Фильтры».
- Лист «Слои» — 20 колонок, ширины колонок как в шаблоне.
- Выгружаются только слои фильтра `*LX:ROOT-FILTER*` (по умолчанию `Стройплэкс`),
  XREF и служебные фильтры `АР` / `Нераспределённые` не выгружаются.
- Лист «Фильтры» — 2 колонки: `Имя фильтра | Список слоев`.
- У родительского фильтра пишутся **собственные** слои (без слоёв потомков),
  затем токены `>>Дочерний`:

```text
Стройплэкс | Оси,Основные,...,Штриховка,>>Витражи,>>Окна,>>Отключенные,>>Фасад
Фасад      | >>Облицовка,>>Подсистема,>>Утепление
```

- Если файл совпадает с действующим шаблоном, печатается `[Предупр.]`.

## Импорт

- Читает кодировку из пролога (`encoding=`) или перебирает `utf-8` → `windows-1251` → `unicode`.
- Создаёт/обновляет слои из листа «Слои».
- Для существующих слоёв **не трогает** видимость, заморозку, «заморожен в новых ВЭ»
  и блокировку (биты 1, 2, 4 кода 70). Остальные свойства — из XML.
- Удаляет **все пользовательские фильтры** чертежа-приёмника
  (`*LI:DELETE-ALL-FILTERS*`), системные не трогает.
- Создаёт фильтры из листа «Фильтры» (поддержка `>>`-вложенности).
- Создаёт `АР` — все не-XREF слои чертежа вне фильтров шаблона.
- Создаёт `Нераспределённые` — слои старых фильтров `Витражи/Фонари/Фасад`
  (поиск по подстроке, без регистра), не вошедшие в шаблон.
- Печатает таблицу «Сверка старых фильтров» и итоговые строки:
  `Фильтр АР: N слоёв (...)` и `Нераспределённые: K слоёв (...)`.

## Шаблон фильтров

```text
Все
├─ АР                          (генерируется)
├─ Нераспределённые            (миграция)
├─ Вн-ссылки                   (системный)
├─ Все используемые слои       (системный)
├─ Все слои без внешних ссылок (системный)
└─ Стройплэкс
   ├─ Витражи
   ├─ Окна
   ├─ Отключенные
   └─ Фасад
      ├─ Облицовка
      ├─ Подсистема
      └─ Утепление
```

Системные фильтры не удаляются и не экспортируются.

## Поведение существующих слоёв

| Параметр | Что происходит |
|---|---|
| Цвет ACI | Значение из XML; знак — от текущего (видимость сохраняется) |
| Тип линии | Из XML |
| Вес линии | Из XML |
| Описание | Из XML |
| Прозрачность / стиль печати | Из XML |
| **Видимость (вкл/выкл)** | **НЕ ТРОГАЕТСЯ** |
| **Заморожен** | **НЕ ТРОГАЕТСЯ** |
| **Заморожен в новых ВЭ** | **НЕ ТРОГАЕТСЯ** |
| **Заблокирован** | **НЕ ТРОГАЕТСЯ** |

Для новых слоёв применяются все параметры из XML.

## Ограничения

- Переносятся только слои и фильтры. Объекты, блоки, текстовые/размерные стили,
  типы линий не экспортируются.
- XREF-слои при импорте пропускаются (бит 16 кода 70).
- `-LAYER _Filter _Set` не используется (fatal error в AutoCAD 2013).
- Импорт удаляет все пользовательские фильтры приёмника — делайте копию чертежа.
- В AutoCAD 2013 недоступны `MLEADERLAYER`, `TABLELAYER`, `REVCLOUDLAYER`,
  `VIEWPORTLAYER` — они пропускаются.

## Требования

- AutoCAD 2013 / LT 2013 или новее (проверено на 2018, 2023).
- Поддержка ActiveX (`vl-load-com`).
- ADODB.Stream (Windows) для чтения XML в UTF-8/1251.
