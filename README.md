Модули AutoCAD LISP для управления слоями.

## Состав проекта

- `00_LoaderChecker.lsp` - загрузчик и базовая проверка синтаксиса

- `02_LayerExport.lsp` - экспорт слоёв и фильтров в XML

- `МОИСЛОИТЕКУЩИЕ` - показать текущие значения переменных
